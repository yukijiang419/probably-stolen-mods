# 深空当铺 Mods / Probably Stolen Mods

为 Steam 游戏《深空当铺：可能是偷的》（Probably Stolen）制作的几个 mod，基于游戏官方的 mod 加载器、C# 和 [Harmony](https://github.com/pardeike/Harmony) 运行时补丁。

| Mod | 说明 | 创意工坊 |
|---|---|---|
| [利润助手 / Profit Helper](profit_help) | 顾客来买东西时，在预算内算出总价最高的商品组合，框出来并可自动放上柜台 | [3832217636](https://steamcommunity.com/sharedfiles/filedetails/?id=3832217636) |
| [物品复制 / Item Copy](item_copy) | 右键菜单加一项「复制」，完整复制物品（含特性、内容物） | [3832200801](https://steamcommunity.com/sharedfiles/filedetails/?id=3832200801) |
| [拾荒不捡垃圾 / No Junk Scavenging](no_junk) | 垃圾场拾荒不再出垃圾，其他掉落比例不变 | — |

## 利润助手

- **最佳组合**：顾客的预算有限，挑最贵的不一定总价最高。这是一个子集和（0/1 背包）问题，用动态规划求解；预算很大时按比例缩放，保证每帧计算的开销；要求「种类多样」的顾客按分组背包处理。
- **价格模拟**：物品放上柜台后才会套上各种加成。预测价格时先保存物品的特性和状态，按游戏自己的顺序依次应用柜台加价、每日行情、天赋、讨价还价回调、违禁品和特殊顾客折扣、验货揭穿的缺陷，算完再全部还原，所以预测价和实际成交价一致，其他 mod 通过 Harmony 加的效果也会被算进去。
- **自动上架**：每位顾客到柜台时自动放上推荐物品；顾客买完一批、柜台空了而预算还有剩，会自动补下一批。
- **筛选**：违禁品、赃物、假标签、橱窗、按物品标签，都可以选择卖或不卖；右键「禁售」的物品（以及装着它的容器）放不上柜台，标记跟着存档保存，并显示红点。
- **兼容**：搜遍背包、箱子、储藏舱里的所有容器；与「店铺助手」的禁售互通；右键菜单采用不破坏原结构的包裹方式，多个 mod 同时加按钮也不会互相覆盖。

## 构建

每个 mod 是一个独立的 .NET Standard 2.1 项目，引用游戏自带的 `Assembly-CSharp.dll`、UnityEngine 和 `0Harmony.dll`（不包含在仓库里）。把仓库放在游戏目录下的 `Modding` 文件夹（`<游戏目录>\Modding\<mod名>\`），然后：

```bash
cd profit_help
dotnet build -c Release
```

编译后会自动安装到 `<游戏目录>\Mods\<mod名>\`，重启游戏、在 Mods 菜单里启用即可。游戏目录在别处时，用 `-p:GameDir=游戏目录` 指定。

适配游戏版本 0.46。所有 mod 都不需要额外权限（不读写文件、不联网）。
